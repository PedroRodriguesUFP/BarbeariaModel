### Decisão sobre as avaliações (ligar ou não à marcação)

**Não liguei.** Razões:

1. Nem a Fase 1 nem a app têm a regra «só se pode avaliar quem nos atendeu». Acrescentá-la só para justificar uma FK composta seria inventar uma regra de negócio.
2. Ligar obrigaria a reescrever `ReviewController`, `ReviewPolicy`, as views de avaliações e os testes (hoje qualquer cliente avalia qualquer barbeiro/serviço, com `morphs`).
3. O diagrama Chen já modela `AVALIAÇÃO` ligada a cliente, barbeiro e serviço, sem ligação à marcação.

O que se perde: o BD não impede avaliar um barbeiro que nunca atendeu o autor. Se o grupo quiser essa regra, é uma decisão de negócio nova e a forma declarativa é `reviews.appointment_id` + FK compostas `(appointment_id, barber_id)` e `(appointment_id, service_id)` para `appointments` (precisa de `UNIQUE (id, barber_id)` e `UNIQUE (id, service_id)`), eliminando então `reviewer_id` (deriva de `appointments.customer_id`).

## 5. Valores físicos vs. conceptuais

| Conceptual (Fase 1) | Físico (BD + Laravel) |
|---|---|
| papel: admin / barbeiro / cliente | `admin` / `barber` / `client` |
| estado da marcação: pendente / confirmada / cancelada / concluída | `pending` / `confirmed` / `cancelled` / `completed` |
| método: numerário / cartão / MB Way / transferência | `cash` / `card` / `mbway` / `transfer` |
| estado do pagamento: pendente / pago / falhado / reembolsado | `pending` / `paid` / `failed` / `refunded` |
| categoria: cabelo / barba / cabelo e barba / degradé / coloração | `hair` / `beard` / `hair and beard` / `fade` / `coloring` |
| estado da subscrição: ativa / suspensa / cancelada / expirada | `active` / `suspended` / `cancelled` / `expired` |

**Limitação da Opção A:** sem `price_applied`, o preço de uma marcação já feita é o `services.price` atual. Se o preço do serviço mudar, o histórico de Q05/Q06 não muda (usa `payments.amount`, que é o montante cobrado), mas qualquer cálculo «preço da marcação» passaria a usar o preço novo. Não acrescentei a coluna porque o prompt só a pede se houver mais de um serviço por marcação.
